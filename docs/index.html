object (playlistItemFilter)
Example: $or=[object Object],[object Object],[object Object]

Structured filter to narrow down the results, a nested array of values indexed by conditions and keyed by comparison and logical operators, inspired by the Strapi REST API filters.

Filterable fields: playlistId, title, artist, featuring, album, soundtrack, genre and xxxCustomProperties.

Comparison operators: $eq, $ne, $contains, $notContains, $gt, $gte, $lt, $lte, $in, $notIn, $between, $null, $notNull.

Logical operators: $and, $or.

An object keyed by a field name applies a comparison to that field: {"title": {"$contains": "Black"}}.

Logical operators combine sub-filters in an array and can be nested arbitrarily: {"$and": [{"artist": {"$eq": "Samurai"}}, {"$or": [{"genre": {"$contains": "Rock"}}, {"genre": {"$contains": "Jazz"}}]}]}.

Multiple filter objects at the same level are implicitly combined with $and.

Filterable fields that take multiple values (artist, featuring, soundtrack, genre) can be matched with $contains to test for a single value.

The object is serialised as nested query parameters, e.g.

filters[$or][0][artist][$eq]=Samurai&filters[$or][1][artist][$contains]=Silverhand.
